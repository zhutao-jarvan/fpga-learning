# FPGA 学习工具环境 - 2026-10-08

当前使用两台通过 NFS 共享源文件的机器：

- 当前机器有 VS Code 和 ChatGPT，用于阅读、编辑、讨论和整理学习记录；
- 另一台服务器安装了 VCS 和 Verdi，但没有 VS Code 和 ChatGPT，用于编译、运行仿真、生成/查看波形和调试 RTL；
- 两台机器访问同一份仓库，因此 RTL、testbench、VCS 日志和波形文件应使用清晰、稳定的相对路径。

后续学习以 VCS + Verdi 工作流为主。Icarus Verilog 等开源仿真器可以用于当前机器上的快速语法检查或基础回归，但不能替代在 VCS/Verdi 服务器上的正式仿真和波形分析。

建议的基本流程：

1. 在当前机器编写 RTL、testbench 和学习说明；
2. 在 VCS 服务器从 NFS 共享目录编译并运行仿真；
3. 使用 Verdi 检查 FSDB/VCD 中的接口握手、时序、状态和波形；
4. 将重要观察结果和结论记录回本仓库。
