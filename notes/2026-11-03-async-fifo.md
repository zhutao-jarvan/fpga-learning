## 实现与验证证据

写域只在 `wr_valid_i && wr_ready_o` 时写当前 binary 地址，并更新 binary/Gray
候选状态；读域采用 FWFT，`rd_valid_o && rd_ready_i` 时消费当前队首。两个方向只
跨域传递注册 Gray 指针，并且 full/empty 功能判断只使用同步第二级。

`make async_fifo_sim` 最终报告：

最终仿真时间为 1136 ns。TB 覆盖：

- 复位后可写、不可读；
- 单笔写入、FWFT 显示、反压保持和读取；
- 空读及满写拒绝；
- 4-entry 写满和 full/empty 的跨域保守解除；
- 多次指针回绕；
- 两域并发读写；
- 数据不丢失、不重复、不乱序。

## 关键波形理解

第一笔 `A5` 在 76 ns 写入 `mem[0]`，写 binary/Gray 指针沿后更新为 `001`。
写 Gray 在读域 85/95 ns 依次到达同步第一级/第二级；注册 `rd_empty` 在 105 ns
解除，此后 FWFT 输出 `A5`。115/125 ns 读端反压期间 valid/data 保持，135 ns
接受读取后读 binary/Gray 更新为 `001`，empty 同沿置位。

随后 `10/11/12/13` 在 156/172/188/204 ns 写入槽位 1/2/3/0；第四笔后写指针
为 binary `101`、Gray `111`，相对同步读 Gray `001` 满一整圈。220 ns 的 `DE`
因 full 被拒绝。235 ns 读取 `10` 并将读 Gray 更新为 `011`；该变化在写域
236/244 ns 到达两级同步寄存器，注册 full 到 252 ns 才解除。这是安全的假满窗口：
暂时少接受写入，但不会过早覆盖未读槽位。

用户能够解释 next-state 是当前状态与沿前输入形成的候选沿后状态，而不是独立计数器；
能够区分同步第二级解决远端指针安全性、next pointer 解决本地边界状态对齐。评审中
修复了直接使用同步第一级进行 full/empty 判断的问题；普通 RTL 仿真仍可能通过该错误，
因为它不模拟亚稳态和物理偏斜。

## Gray full 推导

深度 4 的满状态在 binary 中表示写指针比读指针多 4：只翻转额外回绕位，低两位
不变。对于 `g2=b2`、`g1=b2^b1`、`g0=b1^b0`，翻转 binary 的 `b2` 会使 Gray
的 `g2/g1` 取反，而 `g0` 保持。因此 full 比较需要将同步读 Gray 的最高两位取反、
其余位保持，再与候选写 Gray 比较。详细推导记录在 `rtl/fifo/README.md`。

## 工程模式复盘

这是用分布式槽位所有权解耦两个时钟域的环形缓冲模式。它解决单笔 request/ack
每笔都等待往返确认的吞吐限制：只要不满，写端可每个写时钟接受一笔；只要非空，
读端可每个读时钟消费一笔，并吸收有限突发和短期速率差。

关键不变量是：每个指针只由所属时钟域驱动；指针只在本地 acceptance 时推进；
跨域只传注册 Gray 指针；第一级只驱动第二级；写端不覆盖未释放槽位；读端不读取
未发布槽位；反压时 FWFT valid/data 保持。同步延迟只允许产生保守的假满/假空，
不能产生可能导致覆盖或重复读取的假不满/假非空。

常见错误包括：将 binary 的满条件直接套到 Gray、把 next-state 写成第二个计数器、
使用同步第一级做功能判断、注册 flag 却比较 current pointer、逐 bit 同步数据总线，
以及把 RTL 仿真 PASS 当成物理 CDC 安全证明。

教学实现省略独立复位恢复、任意深度、水位、包边界、生产参数化、同步器属性、
Gray bus skew/最大延迟约束、CDC/STA 报告、RAM read-during-write 语义和形式验证。
FWFT 的组合 memory 读口也不保证映射到所有目标 FPGA 的期望 block RAM 结构。

网络 FPGA 中，异步 FIFO 常用于 MAC/PCS、PCIe、数据面流水线、CSR/功能时钟域之间
传递数据、描述符、元数据或事件。FIFO 只提供有限缓冲；长期生产速率高于消费速率时
仍会满，系统必须有反压、丢弃或流控策略。
