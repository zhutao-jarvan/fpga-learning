# fpga-learning

面向软件/网络工程师的实用 FPGA 学习仓库，以小型 RTL、testbench、
VCS 仿真和 Verdi 波形分析逐步建立工程能力。

- [学习路线](learning-plan.md)：按每周 10–15 小时估算的六阶段计划；实际按掌握情况推进，可提前学习或暂停。
- [总体学习进度](learning-progress.md)：当前阶段、完成证据、待补齐内容和下一步；继续学习时先看这里。
- [能力评估历史](assessment.md)：已有基础与评估快照，保留历史供对照。
- [学习日志](notes/README.md)：每日观察、问答、工具经验和波形记录。
